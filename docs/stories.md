# Stories: «Какая ты фея геймдева?»

Brief: the Brief for this quiz, in the same folder.

## Stories

- S1. As a teen, I want to find out which game-making role fits me, so that I see a place for myself in making games.
  - Six questions, fixed order, four answers each.
  - Exactly one result, chosen by points; a tie goes to the tied fairy that most recently got the two points.
- S2. As a teen, I want to change my answer until I confirm it, so that one wrong tap does not decide my result.
  - No going back to a confirmed question.
- S3. As a teen, I want my whole result on one phone screen, so that one screenshot shows all of it.
  - Fits small phones too.
- S4. As a teen, I want to reach the school from my result in one tap, so that I can learn to make games if the result hooks me.
- S5. As a teen, I want to take the quiz again from a clean start, so that I can try for another fairy.
- S6. As a teen, I want to play without giving anything about myself, so that the quiz is safe to open from any link.
  - No registration, personal data or analytics.
- S7. As a friend who got a screenshot, I want to see a funny, clear result, so that I want my own.
- S8. As the school owner, I want every result to carry the school's invitation, so that every player sees where to learn.
  - Exact approved invitation and link on all six results.
- S9. As the school owner, I want the approved illustrations and text shown unchanged, so that the quiz is what I approved.

## Accepted limits

- Friend finding the quiz: the requested result card shows only the school's address, not the quiz's own address. A friend who has only the screenshot is not led to the quiz.
- Friend reaching the school: sharing is by screenshot only, so the school's link in a screenshot cannot be tapped.
- out: "No analytics, no registration, no personal data." The school owner gets no count of players.
- out: "Share by screenshot only." No share button or per-result link.
